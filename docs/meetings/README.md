# Meeting Notes

One file per meeting: `YYYY-MM-DD-<type>.md` (supervisor, study-group, interview, pilot).
Write it the same day.

```
# Supervisor meeting: DD Mon YYYY

## Attendees
## Progress since last meeting
## Feedback received
## Actions (each becomes a GitLab issue: link it)
- [ ] #__
## How previous feedback was acted on
```
